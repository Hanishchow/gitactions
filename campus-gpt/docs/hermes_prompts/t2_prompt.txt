BUILD:
A) ingest/: extract text from PDF (per page), PPTX (per slide, include notes), DOCX (per heading section), and plain .txt/.md. API: extract_file(path) -> list of {text, location} where location is {"page": n} or {"slide": n} or {"section": title}. Handle empty/scanned pages by skipping with a logged warning, never crashing.
B) chunking: split into ~800-character chunks with 120-char overlap on sentence/paragraph boundaries, never splitting inside a word. Each chunk: {id, text, file, location, subject (code or None), module (int or None), char_len}. Infer subject/module only from filename patterns like "BCS502-module-3-textbook.pdf" or "Module-4_Notes.pdf" using one regex helper, otherwise None. Write chunks to data/chunks.jsonl (UTF-8, one JSON per line). CLI: python -m ingest.build --input data/raw --out data/chunks.jsonl.
C) rag/: BM25 index built from chunks.jsonl, saved/loaded as a file (pickle or json). API: Retriever.load(path); retrieve(query, k=5, subject=None, module=None) -> list of {chunk, score}. Lowercase, simple tokenizer, small stopword list, subject-code tokens like "BCS502" and "22AI31" must stay intact as single tokens and match case-insensitively. Also a structured lookup over subjects.yaml: find_subject(code_or_name) and get_module(code, number). Optional embedding backend behind a flag (use_embeddings=False by default) that imports sentence_transformers lazily and is NOT exercised by tests.
D) Return a clear "no result" signal (empty list) when the best BM25 score is below a configurable min_score; never return unrelated chunks to look helpful.
E) tests/: synthetic fixtures generated inside the tests (build a tiny PDF with reportlab or fpdf2, a PPTX with python-pptx, a DOCX with python-docx) covering: each extractor, chunk size/overlap/word-boundary rules, filename inference, subject-code token matching, retrieval ranking on a hand-checkable query, subject/module filters, below-threshold returns empty, index save/load roundtrip.
F) README.md for the package: install, run ingest, query from Python.
