# Contracts for parallel work (controller rulings)

## A. model_weights.h layout (written by T6 `ethylene/export.py`, read by T7 firmware `mlp.h`)
Header is include-guarded, starts with `#include <stdint.h>` and `#include <avr/pgmspace.h>`, defines
`MLP_IN 6, MLP_L1 256, MLP_L2 128, MLP_L3 64, MLP_L4 32, MLP_OUT 1`, then PROGMEM arrays, all flat row-major `[out][in]`:
`const int8_t W1[256*6] PROGMEM`, `W2[128*256]`, `W3[64*128]`, `W4[32*64]`, `W5[1*32]`;
`const float S1[256] PROGMEM` (per-output-row scale), `S2[128]`, `S3[64]`, `S4[32]`, `S5[1]`; `const float B1[256] PROGMEM`, `B2[128]`, `B3[64]`, `B4[32]`, `B5[1]`;
`const float SCALER_MEAN[6] PROGMEM`, `SCALER_STD[6] PROGMEM`.
Forward: `a0 = (x - SCALER_MEAN) / SCALER_STD`; layer l: `a_out[j] = (sum_i W[j*in+i] * a_in[i]) * S[j] + B[j]`; ReLU after layers 1-4, none after layer 5.
Output = ripeness index (float, not clamped). Floats are printed with `%.9g` plus `f` suffix.
Until T6 runs, T7 ships a zero-filled placeholder header with the same names/sizes (first line comment: PLACEHOLDER, regenerated by `python -m ethylene.export`).

## C. Parallel-work git discipline (several agents share one checkout)
Never `git add -A`/`git add .`, never stash/checkout/reset/rebase/clean. Commit only your own files: `git add <your paths>` then `git commit -m "..." -- <your paths>` (retry after 2 s on index.lock). Run only your own test files, not the whole suite (other tasks' files may be half-written); ignore failures clearly caused by another task's files. `ethylene/data.py` (T2) is being written concurrently; if you need it and it is not committed yet, wait and retry (check `git log --oneline`), never create it yourself.
